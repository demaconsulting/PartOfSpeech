This record belongs to the fourth held-out evaluation of the model family: the held-out sets were already seen for the
first retrained model, again for the model that followed it and again for the model with the clause-cue feature group
(and for the model before the label corrections, so five models in all have been scored on them), so this evaluation
is a disclosed fourth look, not a first look at unseen data. The model was selected on development data only, by a rule
that was fixed before any training (the section "Imperative training data" of
[`RUN-LOG.md`](../../tools/DemaConsulting.PartOfSpeech.Trainer/RUN-LOG.md)), and the registration of that experiment
provided for this one evaluation if a candidate shipped; nothing was selected, tuned or changed on its result, and the
previous model is shown beside it (see the [evaluation overview](README.md)).
